# Who decides which camper a record belongs to

Generated by `node scripts/camper_name_inventory.js`. Do not edit by hand:
`tests/camper_name_inventory.test.js` fails when this file is out of date,
when anything in part A is not zero, and when any count goes **up**.

## The rule

A camper is identified by their **camper number**, issued by the server — or by their **roster key**, which the server binds to exactly one number. A name is only ever shown.

- **Numbers are issued by the server**, one per camper, never shared, never re-issued while anything about the camper exists (253). A rename keeps the number (259).
- **A roster key belongs to one camper** for as long as anything about them exists (259). A new child whose name is taken — by a camper here, by one who left, or by somebody's old name — gets their own key ("Avi Katz #11"), shown as "Avi Katz". Erasing a camper frees their keys and clears what was filed under them. So a key, like a number, can never reach a different child.
- **Every database function** that names a camper takes the number and the number decides (248, 255-258); `scripts/verify_identity_chain.sql` checks this on the live database, row by row.
- **Every call and row the pages send** that names a camper carries the number (campistry_camper_id_rpc.js), and every saved record is written with it.
